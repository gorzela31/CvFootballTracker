# classicalApproachPlayground

Katalog zawiera wcześniejsze eksperymenty z klasycznym podejściem do wyznaczania geometrii boiska bez wykorzystania finalnych metod opartych na uczeniu głębokim.

Testowane były między innymi operacje związane z:

- wydzielaniem obszaru murawy,
- detekcją białych linii,
- detekcją krawędzi,
- transformacją Hougha,
- analizą kierunków i punktów przecięcia linii,
- próbą wyznaczenia macierzy homografii na podstawie wykrytej geometrii.

Katalog ma charakter eksperymentalny i dokumentacyjny. Zawarte tutaj skrypty, notebook i przykładowe obrazy pokazują przebieg wcześniejszych prób oraz ograniczenia podejścia klasycznego.

Rozwiązanie nie zostało wykorzystane w czterech finalnych wariantach systemu. Finalne porównanie homografii obejmuje metodę opartą na 32 punktach charakterystycznych oraz TVCalib.
